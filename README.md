# WhiteLagoon Villa Management System

## Overview

WhiteLagoon is a Villa Management System developed using ASP.NET Core MVC following Layered Architecture principles.

The application enables efficient management of villa listings through CRUD operations and SQL Server database integration.

---

## Features

* Villa Management
* Create Villa
* Edit Villa
* Delete Villa
* View Villa Details
* Database Integration
* Entity Framework ORM
* Responsive UI

---

## Architecture

Presentation Layer
↓
Application Layer
↓
Domain Layer
↓
Infrastructure Layer
↓
SQL Server
